---
title: Managing Occasions Reference Data
app_section: admin
---

Admins look after the lists that people and events are filed under.

Everyone can view these lists under **Reference Data** in the Occasions left nav. Admins add to them from **Actions › New** (Create Event Type, Create Social Media Platform), and edit or delete them from each one's page.

## Event Types

An Event Type has a **Name**, a **Description** and an **Icon Name** from [lucide.dev/icons](https://lucide.dev/icons/), for example `cake` or `heart`. The icon stands in for an event that has no image.

- Names must be unique, ignoring capitals.
- Each icon can only be used by one Event Type.
- An Event Type **can't be deleted while any event uses it**. Move those events to another type first.

Signed-in users can mute an Event Type from the Event Types list to hide all its events. See *Viewing Events*.

## Social Media Platforms

A Social Media Platform has a **Name**, a **URL** (starting `http://` or `https://`), a **Description** and an optional **Logo** (a JPEG, PNG or WebP smaller than 5MB). People's usernames on it are shown on their page.

- Names must be unique, ignoring capitals.
- A platform **can't be deleted while any person has an account on it**. Remove those accounts first.
