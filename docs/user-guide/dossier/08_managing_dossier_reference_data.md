---
title: Managing Dossier Reference Data
app_section: admin
---

Dossier's Reference Data is shared by everyone who uses it. Everyone can view it under **Reference Data** in the Dossier left nav. Admins add to it from **Actions › Reference Data**, and edit or delete each item from its page.

## What Each One Holds

- **Organisations:** employers, clients, issuers and training providers. A **Name**, an optional **Abbreviation** (headings show the full name with it, running text uses the abbreviation), an **Industry** and a **Website**. Content Creators can add Organisations themselves; only admins edit or delete them.
- **Industries** and **Skill Categories:** a name and an optional description. A Skill Category can also be a sub-category, and can be marked **Professional (Soft) Skills**.
- **Roles:** what someone did for a client, such as Teacher or Test Lead.
- **Locations:** a **City** and **Country**.
- **Employment Types:** a name, plus two boxes. **Permanent** gives each new Engagement one Assignment automatically, with the employer as client. **Personal** marks hobby projects: their years count as personal experience, and the Timeline doesn't treat them as work.
- **Credential Types:** a name, a **Sort Order** (lower numbers come first on Credentials › Credentials) and a **Training** box for courses and workshops.
- **Skills:** a **Name**, **Skill Category**, **Aliases** (other spellings, comma-separated) and an optional **Version Of**. Content Creators can add Skills; only admins edit or delete them.

Names must be unique, ignoring capitals. For a Location, that's its City and Country together.

## Tidying Skills

Skills typed into Tech Stacks, Achievements and Credentials that Dossier doesn't know land in **Uncategorised**. Look there now and then:

- **Move a Skill** to its proper category with **Edit**.
- **Merge** two Skills that are the same, such as "Selenium" and "Selenium WebDriver". On the Skill to remove, choose **Merge Into…** and pick the Skill to keep. Everything that used the old Skill moves across, its name becomes an alias of the kept Skill, and it's deleted.

Uncategorised Skills are left off CVs by default, so filing them matters to everyone's CVs.

## Deleting

Reference Data **can't be deleted while anything uses it**: an Organisation that's an employer, client, issuer, vendor or customer, a Role on an Assignment, a Skill in a Tech Stack, and so on. Change those first. Deleting is permanent.
