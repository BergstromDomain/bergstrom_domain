Admins look after the lists recipes are filed under, and can restore deleted recipes.

## Cuisines, Food Types and Languages

Everyone can view these lists under **Reference Data** in the Cookbook left nav. Admins add to them from **Actions › New** (Add A Cuisine, Add A Food Type, Add A Language), and edit or delete them from each one's page.

- A **Cuisine** has a name, a flag emoji (shown on recipes without an image) and a description.
- A **Food Type** has a name, a description and a Lucide icon name, e.g. `soup` or `cooking-pot`. Each icon can only be used once.
- A **Language** has a name, a two-letter language code (e.g. `sv`) and a flag. It marks which language a recipe is written in.

Names must be unique. A Cuisine, Food Type or Language **can't be deleted while any recipe uses it**, even as a recipe's second choice. Move those recipes first.

## Deleted Recipes

**Actions › New › Deleted Recipes** lists recipes that have been deleted in the last 30 days, with how many days each has left before it's removed for good. **Restore** puts a recipe back exactly as it was, published or draft. After 30 days, deleted recipes are purged automatically.
